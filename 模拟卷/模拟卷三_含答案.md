## 四、简答题参考答案

### 1.（6 分）
中序 D B A E C F，后序 D B E F C A。

根 A，左子树中序 DB（后序 DB），右子树中序 ECF（后序 EFC）。
左子树：根 B，左 D。
右子树：根 C，左 E，右 F。

```
二叉树：
      A
     / \
    B   C
   /   / \
  D   E   F
```

（1）二叉树如上。
（2）先序遍历：**A B D C E F**
　　层次遍历：**A B C D E F**
（3）中序遍历为 D B A E C F，不是升序序列（B > A），所以不是二叉排序树。

### 2.（6 分）
H(k) = k % 11：

| key | 19 | 14 | 23 | 1 | 68 | 20 | 84 | 27 | 55 | 11 |
|-----|----|----|----|---|----|----|----|----|----|----|
| H(k)| 8 | 3 | 1 | 1 | 2 | 9 | 7 | 5 | 0 | 0 |

（1）链地址法哈希表：
```
地址0: 55 -> 11 -> NULL
地址1: 23 -> 1 -> NULL
地址2: 68 -> NULL
地址3: 14 -> NULL
地址4: (空)
地址5: 27 -> NULL
地址6: (空)
地址7: 84 -> NULL
地址8: 19 -> NULL
地址9: 20 -> NULL
地址10:(空)
```

（2）各关键字查找长度：55(1), 11(2), 23(1), 1(2), 68(1), 14(1), 27(1), 84(1), 19(1), 20(1)
ASL = (1+2+1+2+1+1+1+1+1+1)/10 = 12/10 = **1.2**

（3）链地址法数据类型定义：

typedef struct LNode {

### 3.（6 分）
频率 {A:8, B:16, C:4, D:12, E:6}

构造过程：
1. 最小 C(4), E(6) → 合并得 10（左 C 右 E）
2. 最小 A(8), 10 → 合并得 18（左 A 右 10）
3. 最小 D(12), 18 → 合并得 30（左 D 右 18）
4. 最小 B(16), 30 → 合并得 46（左 B 右 30）

```
哈夫曼树：
        46
       /  \
     B(16) 30
          /  \
        D(12) 18
             /  \
           A(8) 10
                / \
              C(4) E(6)
```

（2）WPL = 16×1 + 12×2 + 8×3 + 4×4 + 6×4 = 16 + 24 + 24 + 16 + 24 = **104**

（3）哈夫曼编码（左 0 右 1）：
- B：0
- D：10
- A：110
- C：1110
- E：1111

优劣比较：哈夫曼编码是变长编码，对频率高的字符用短编码，频率低的用长编码，平均编码长度短，可压缩数据；等长编码每个字符编码长度相同（此处需 ⌈log₂5⌉ = 3 位），实现简单但无压缩效果。

### 4.（6 分）
顶点集 {A,B,C,D,E,F}，边集带权。

（1）Prim 算法思想：从某一顶点出发，每次选取一条连接已选顶点集合和未选顶点集合的权值最小的边，将新顶点加入集合，直到所有顶点都被加入。

（2）从 A 出发：
- 初始 S = {A}，候选边：(A,C)3, (A,B)7
- 选 (A,C)3，S = {A,C}，候选边：(A,B)7, (C,B)4, (C,D)5, (C,E)6
- 选 (C,B)4，S = {A,C,B}，候选边：(B,D)2, (C,D)5, (C,E)6

void DeleteOdd(LinkList L) {
    LNode *pre = L;           // pre 指向当前结点的前驱
    LNode *p = L->next;       // p 指向当前结点
    while (p != NULL) {
        if (p->data % 2 != 0) {   // 奇数
            pre->next = p->next;
            free(p);
            p = pre->next;
        } else {
            pre = p;
            p = p->next;
        }
    }
}

// (2) 对单链表进行升序排序（直接插入排序思想）
void SortList(LinkList L) {
    if (L->next == NULL || L->next->next == NULL)
        return;
    LNode *p = L->next->next;   // 从第二个结点开始
    L->next->next = NULL;        // 第一个结点作为有序部分
    while (p != NULL) {
        LNode *q = p->next;      // 保存后继
        // 在有序部分找到插入位置
        LNode *pre = L;
        while (pre->next != NULL && pre->next->data < p->data)
            pre = pre->next;
        // 插入 p 到 pre 之后
        p->next = pre->next;
        pre->next = p;
        p = q;
    }
}

// 栈的基本操作
int Push(SqStack *S, char c);
int Pop(SqStack *S, char *c);
int StackEmpty(SqStack *S);
char GetTop(SqStack *S);

// (1) 判断字符串是否为回文
int IsPalindrome(char str[], int n) {
    SqStack S;
    S.top = -1;
    // 将前半部分字符入栈
    for (int i = 0; i < n / 2; i++)
        Push(&S, str[i]);
    // 从中间位置（跳过奇数长度的中间字符）开始与栈中元素比较
    int start = (n % 2 == 0) ? n / 2 : n / 2 + 1;
    for (int i = start; i < n; i++) {
        char c;
        Pop(&S, &c);
        if (str[i] != c)
            return 0;
    }
    return 1;
}

// (2) 中缀表达式转后缀表达式
// 返回运算符优先级
int Priority(char op) {
    if (op == '+' || op == '-') return 1;
    if (op == '*' || op == '/') return 2;
    if (op == '(') return 0;
    return -1;
}

void InfixToPostfix(char infix[], char postfix[]) {
    SqStack S;
    S.top = -1;
    int j = 0;
    for (int i = 0; infix[i] != '\0'; i++) {
        char c = infix[i];
        if (c >= 'a' && c <= 'z') {      // 操作数直接输出
            postfix[j++] = c;
        } else if (c == '(') {
            Push(&S, c);
        } else if (c == ')') {
            char top;
            while (!StackEmpty(&S) && (top = GetTop(&S)) != '(') {
                Pop(&S, &top);
                postfix[j++] = top;
            }
            Pop(&S, &top);   // 弹出 '('
        } else {              // 运算符
            while (!StackEmpty(&S) && Priority(GetTop(&S)) >= Priority(c)) {
                char top;
                Pop(&S, &top);
                postfix[j++] = top;
            }
            Push(&S, c);
        }
    }
    // 弹出栈中剩余运算符
    while (!StackEmpty(&S)) {
        char top;
        Pop(&S, &top);
        postfix[j++] = top;
    }
    postfix[j] = '\0';
}
