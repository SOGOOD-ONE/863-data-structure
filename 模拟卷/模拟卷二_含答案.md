## 一、单项选择题答案

**解析：**

- **第 1 题**：广义表 L = (a, (b,c), ((d)))，长度为最外层元素个数 3；深度为括号嵌套层数，最深为 ((d)) 共 3 层。选 A。

- **第 2 题**：对称矩阵下三角按行优先，A[i][j]（i≥j）前面有 i 行，第 i 行前有 j 个元素。前 i 行元素数 = 0+1+2+...+(i-1)+i = i(i+1)/2，再加 j。下标 = i(i+1)/2 + j。选 A。

- **第 3 题**：完全二叉树 n0 = 124，n2 = n0 - 1 = 123。n = n0 + n1 + n2 = 124 + n1 + 123 = 247 + n1。完全二叉树 n1 只能为 0 或 1。最多结点时 n1 = 1，n = 248。选 B。

- **第 4 题**：入度为 0 的顶点可能有多个，拓扑排序结果不唯一。D 说"唯一"是错误的。选 D。

- **第 5 题**：二叉排序树的中序遍历一定是升序序列，与插入顺序无关。选 A。

- **第 6 题**：序列 {49, 38, 65, 97, 76, 13, 27, 49}，d=4。索引差 4 的为一组：
  - 组1：A[0]=49, A[4]=76 → 已有序
  - 组2：A[1]=38, A[5]=13 → 排序后 13, 38
  - 组3：A[2]=65, A[6]=27 → 排序后 27, 65
  - 组4：A[3]=97, A[7]=49 → 排序后 49, 97
  放回：A[0]=49, A[1]=13, A[2]=27, A[3]=49, A[4]=76, A[5]=38, A[6]=65, A[7]=97
  结果：{49, 13, 27, 49, 76, 38, 65, 97}。选 A。

- **第 7 题**：A 的左孩子平衡因子 0，右孩子平衡因子 1，说明右孩子的右子树高，属于 RR 型。但题目说"最低不平衡结点 A"，A 的平衡因子应为 -2（右重）。A 的右孩子平衡因子为 1 说明右孩子也是右重，所以是 RR 型。选 D。**修正：第 7 题答案应为 D（RR）。**

  等一下，平衡因子为 1 表示左子树比右子树高 1。A 的右孩子平衡因子为 1，说明右孩子的左子树高。所以 A 右重，A 的右孩子左重 → 这是 RL 型。选 C。
  
  重新分析：平衡因子 = 左子树高度 - 右子树高度。A 不平衡且是最低不平衡结点。A 的左孩子 BF=0，右孩子 BF=1。BF=1 表示左子树比右子树高。A 的右孩子左重 → 新结点插在 A 的右孩子的左子树上 → RL 型。选 C。

- **第 8 题**：对称矩阵，A[7][3] 属于下三角（7≥3）。前 7 行元素数 = 0+1+...+7 = 28。第 7 行第 3 列前有 3 个元素。B 中位置 = 28 + 3 = 31。地址 = 100 + 31×2 = 162。选 C。**修正：答案应为 C（162）。**

  重新算：i=7, j=3。i(i+1)/2 + j = 7×8/2 + 3 = 28 + 3 = 31。地址 = 100 + 31×2 = 162。选 C。

- **第 9 题**：第一趟 {20,15,21,25,47,27,68,35,84}，中间 25 是枢轴，左边小于 25，右边大于 25，这是快速排序。但第二趟结果显示左右分别有序，更像归并。实际上看第一趟：25 是枢轴，{20,15,21} < 25 < {47,27,68,35,84}。第二趟对左右分别快排。这是快速排序。选 B。

  等一下，第二趟 {15,20,21,25,35,27,47,68,84}。左边 {20,15,21} 排序后 {15,20,21}，右边 {47,27,68,35,84} 排序后 {35,27,47,68,84}（枢轴 47）。这确实是快速排序的特征。选 B。

  但仔细看第三趟直接全有序了，快排通常不会这么快。让我再看：第二趟右边 {47,27,68,35,84}，枢轴 47，结果 {35,27,47,68,84}。第三趟对 {35,27} 排序得 {27,35}，对 {68,84} 已基本有序。最终 {15,20,21,25,27,35,47,68,84}。这是快速排序。选 B。

  但选项 C 归并排序也有可能。归并排序第一趟两两归并：{25,84}→{25,84}, {21,47}→{21,47}, {15,27}→{15,27}, {68,35}→{35,68}, {20}→{20}。结果 {25,84,21,47,15,27,35,68,20}。与题目第一趟不符。所以不是归并。选 B（快速排序）。

  实际上再仔细看题目第一趟结果 {20,15,21,25,47,27,68,35,84}：枢轴 25，左侧 {20,15,21} 都小于 25，右侧 {47,27,68,35,84} 都大于 25。这明显是快速排序。选 B。

- **第 10 题**：H(23)=23%11=1, H(14)=14%11=3, H(31)=31%11=9, H(56)=56%11=1, H(47)=47%11=3, H(68)=68%11=2, H(72)=72%11=6。哈希地址为 1 的关键字有 23、56，共 2 个同义词。选 B。

- **第 11 题**：先序 ABDEGCFH，中序 DBGEACHF。根 A，左子树中序 DBGE（先序 BDEG），右子树中序 CHF（先序 CFH）。左子树根 B，B 的左 D，右子树中序 GE（先序 EG）→ 根 E，E 的左 G。右子树根 C，C 的左 H？不对，右子树中序 CHF，先序 CFH。根 C，左子树中序空，右子树中序 HF（先序 FH）→ 根 F，F 的左 H。
  树：
  ```
        A
       / \
      B   C
     / \   \
    D   E   F
       /   /
      G   H
  ```
  后序：D G E B H F C A → DGEBHFCA。选 A。

- **第 12 题**：当前已求得到 v1(5), v2(9), v3(12)。v4 通过 v2 的距离 = 9+3 = 12，通过 v3 的距离 = 12+1 = 13。取最小 12。下一个最短路径是到 v4（距离 12，与 v3 相同但题目说已求得 v3）。等等，v3 的距离是 12，v4 通过 v2 也是 12。如果按 Dijkstra，已确定 v1(5), v2(9), v3(12)。现在 v4 的暂定值 = min(∞, 9+3, 12+1) = 12。下一个确定的是 v4（距离 12）。选 D。

  但等等，v3 已经确定了距离 12。v4 的距离也是 12。Dijkstra 每次选最小的未确定顶点。v4=12，和已确定的 v3 一样。所以下一个确定 v4。选 D。

// (1) 查找倒数第 k 个结点（只遍历一次）
LNode* FindKthToTail(LinkList L, int k) {
    if (k <= 0) return NULL;
    LNode *fast = L->next;   // 快指针
    LNode *slow = L->next;   // 慢指针
    // 快指针先走 k 步
    for (int i = 0; i < k; i++) {
        if (fast == NULL) return NULL;  // 链表长度不足 k
        fast = fast->next;
    }
    // 快慢指针同时走，快指针到尾时，慢指针指向倒数第 k 个
    while (fast != NULL) {
        fast = fast->next;
        slow = slow->next;
    }
    return slow;
}

// (2) 判断单链表是否递增有序
int IsAscending(LinkList L) {
    LNode *p = L->next;
    if (p == NULL || p->next == NULL)
        return 1;   // 空表或只有一个结点，视为有序
    while (p->next != NULL) {
        if (p->data > p->next->data)
            return 0;  // 出现逆序
        p = p->next;
    }
    return 1;
}

    if (T == NULL)

    int leftH = TreeHeight(T->lchild);

int IsBST(BiTree T) {
    if (T == NULL)
        return 1;
    if (!IsBST(T->lchild))
        return 0;
    if (T->data <= prev)
        return 0;
    prev = T->data;
    return IsBST(T->rchild);
}
